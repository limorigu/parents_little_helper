7

External Integrations

all optional · user-initiated · no app-owned server

There is no backend written or run by this app. The only network calls are (a) loading two Google Fonts once, and (b) an opt-in mirror of your data to your own Google account.

Google Fonts CDN
Nunito Outfit

Loaded once at startup. Purely presentational, unrelated to app data.

Google Sheets / Drive sync off by default

Triggered only from Settings. Google Identity Services opens an OAuth popup; the access token is kept in memory only (never persisted) and expires after ~1 hour.

Settings page → Google OAuth popup (GIS) → Drive API v3 — folder + media
Zustand store ⇄ Sheets API v4 — 4 tabs: Activity Log · Milestones · Growth · Doctor Visits

Full replace-sync on demand, plus auto-append of new entries as you log them. Import can also read the sheet back in and reparse it into the store. localStorage stays authoritative — sync failures are swallowed silently and never block the app.

No backend, by design
